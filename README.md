# HEADMAN STUDIO

> Лендинг сети мужских парикмахерских. Тёмная тема, золотые акценты, премиальный стиль.

---

## 🌐 Демо

[https://headman-studio.vercel.app](https://headman-studio.vercel.app)

---

## 📋 О проекте

Одностраничный лендинг барбершопа: услуги, мастера, запись онлайн.

**Секции:**
- Hero — заголовок + CTA
- Услуги — 4 карточки с ценами
- Мастера — 3 карточки
- CTA — запись
- Футер — контакты, соцсети

---

## 🧱 Технологии

- **Vue 3** (Composition API)
- **Vue Router**
- **Vite**
- **TypeScript**
- **CSS** (scoped, адаптив)
